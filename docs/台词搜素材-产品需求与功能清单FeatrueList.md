# 台词搜素材 · 产品需求与功能清单（FeatureList）

> 参考对象：GetYarn（getyarn.io）——调研结论见《GetYarn 产品调研报告》
> 产品代号：**「台词搜」**（正式名待定，文中以 [产品名] 占位）
> 版本：v0.1 草案 · 2026-11-05 · 优先级体系：P0 首发闭环必须 / P1 快速跟进 / P2 生态与变现
>
> **与 GetYarn 的三个关键差异**：① 视觉与交互换为轻量极简 + 莫兰迪体系；② 素材形态在视频片段之外新增**视频帧截图**（并支持帧+台词图文合成）；③ 分享链路对准国内平台（抖音 / B站 / 小红书）而非 Twitter/Discord 卡片生态。

---

## A. 产品定位

| 项 | 定义 |
|---|---|
| 一句话定位 | 输入一句台词，拿到一段画面或一帧截图——聊天、发帖、剪视频时的"表达弹药库" |
| 核心 JTBD | "我想用现成的影视画面替我说这句话"（表达/回应），而非"我想找一部电影看" |
| 目标用户 | ① 社媒表达者/表情包用户；② 中小内容创作者（剪辑素材、图文笔记、封面梗图）；③ 台词考据/英语学习者（次级） |
| 首发内容盘 | 国产剧/电影/综艺 + 进口影视中英字幕盘 + 热门动画（具体盘子见 M7） |
| 北极星指标 | **素材被取用率**：周活搜索用户中，发生"下载/分享/取帧"任一动作的比例（对标 GetYarn 的"链接被点开"飞轮） |
| 首要护城河假设 | 华语台词+画面的切片语料库（GetYarn 华语覆盖薄 → 空位），以及"帧截图"这个小红书原生形态 |

**产品气质三原则（从 GetYarn 学来的克制）**
1. 首页 = 一个搜索框，不做信息流运营位绑架。
2. 搜索永不空手：宁可给海量弱相关，不给死胡同；但提供比 Yarn 更多的"收紧"旋钮（精确短语）。
3. 结果即成品：每个结果天然可"拿走"（视频/帧/图文卡三种出口），验证成本 ≤2 秒。

## B. 设计语言规范（轻量极简 · 莫兰迪 + 单点强调）

### B1. 色彩 Token（P0 — 设计系统与前端共用）

| Token | 色值 | 用途 |
|---|---|---|
| `bg/base` 宣纸灰 | `#F5F3EF` | 页面底色（低饱和莫兰迪暖灰基底） |
| `bg/raised` 雾白卡 | `#FBFAF8` | 卡片/浮层底色 |
| `ink/primary` 栗墨 | `#3F3B37` | 主文本 |
| `ink/secondary` 烟灰 | `#948D84` | 次级文本、说明、时间戳 |
| `line/subtle` | `#E7E4DE` | 分隔线、描边（替代阴影的轻量边界） |
| **`accent` 陶土橙** | **`#BC7A5E`** | **全站唯一强调色**：仅用于主按钮、选中态、播放键、分享主操作、热点数字。同屏占比 ≤5% |
| `accent/soft` | `#F0DFD5` | 强调色 12% 浅底（选中态填充、标签底） |
| `state/success` | `#7E9B7B` 鼠尾草绿 | 仅成功提示，小面积 |
| `state/danger` | `#B46A5A` | 仅错误提示（比 accent 更沉，避免双强调打架） |

规则：**莫兰迪低饱和承担 95% 的画面，强调色像"落款"一样只出现一次**；深浅模式同色相，暗色底 `#23211F`（暖炭），accent 提亮 12%。

### B2. 形状与质感

| Token | 值 | 说明 |
|---|---|---|
| `radius/s` | 8px | 图片、输入内元素 |
| `radius/m` | 10px | 按钮、输入框、标签 |
| `radius/l` | 14px | 卡片、弹层 |
| `radius/full` | 999px | 胶囊：筛选 chip、搜索按钮 |
| `shadow/1` 微质感 | `0 1px 2px rgba(63,59,55,.05), 0 4px 12px rgba(63,59,55,.06)` | 卡片默认态："浮起 2mm 的纸片" |
| `shadow/2` | `0 8px 24px rgba(63,59,55,.10)` | hover/聚焦态，仅 +2px 位移 |
| 表面微渐变 | 1%~2% 上浅下深 linear-gradient | 质感来源=极浅渐变+噪点层(opacity .4%)，不用拟物描边 |

### B3. 动效（轻量克制）

- duration：tap 120ms / 状态切换 180ms / 页面元素入场 240ms，全部 ease-out；
- 反馈范式：按压 scale .98 + 阴影收敛；卡片 hover 上浮 2px；播放按钮点击=一次 accent 色轻脉冲；
- 禁用：循环装饰动效、视差、大于 300ms 的入场动画；尊重 `prefers-reduced-motion`。

### B4. 字体与栅格

- 中文：思源黑体/PingFang，数字与计时徽标用等宽 Semi；字重只用 400/600/800 三档。
- 栅格：桌面 12 栏 24px gutter；**桌面卡片流 4→5 列**（低于 Yarn 信息密度，符合极简定位）；移动 2 列，卡间距 12px。

## C. FeatureList 功能清单

| ID | 功能 | 优先级 | 说明 | 对 GetYarn 的取舍 |
|---|---|---|---|---|
| F1.1 | 全局搜索框（首页即搜索） | P0 | 单输入框；placeholder 明示能力边界："输入一句话，找到它的画面（影视台词/歌词/帧）"；回车即搜，结果页保留控件与"×"清空 | 学 |
| F1.2 | 字幕行 × 词倒排全文检索 | P0 | 分词含中文（jieba/大模型分词离线预处理）+ 英文；索引含**非语言声**（笑声/枪声等标注帧，供"反应素材"）；查询端点见 F1.5 | 学 |
| F1.3 | 精确短语开关「仅完整台词」 | P0 | 一键从"词召回"切到"短语匹配"，解决 Yarn「6 词爆 10 万条、无兜底旋钮」的头号痛点；URL 参数 `exact=1` 可分享 | **改**（Yarn 没有） |
| F1.4 | 内容域筛选 | P0 | 电影/剧集/综艺/动画/MV/预告/短视频素材（域按华语盘重划）；tab 即 URL 参数 `type=` | 学+改 |
| F1.5 | 排序三档 | P0 | 相关度(默认)/热度(站内取用数)/新片优先；爆量阈值(>2000 条)时自动置顶"仅完整台词"提示，计数文案分级：`N 条结果` → `5,000+ 条` → `海量结果`（借 Yarn 双档计数，再加中间档） | 改 |
| F1.6 | 高级收紧筛选（🔥Filter 等价物） | P1 | 聚合抽屉：年代/画质/画幅比(9:16,3:4,16:9)/是否带烧录字幕/含帧截图——全部落 URL 参数 | 学+扩展 |
| F1.7 | 搜索联想与热梗补全 | P1 | Yarn 刻意不做；我们做：中文用户无 query 信心，输入 2 字起弹 top1000 台词联想 + 本周热词 | **反**（有意不同） |
| F1.8 | 容错与归一化 | P1 | 错拼纠正提示、拼音输入容错（如 zhuahua→抓马）、繁简与全半角归一、标点模糊 | 补 |
| F1.9 | 空结果兜底 | P0 | 永不空手：给"拆词后的弱相关结果 + 建议加引号/换说法"；全空时推热梗（Yarn 架构天然永不空手，我们显式补引导） | 学+补 |
| F1.10 | 搜索历史 / trending 词 | P1 | 本地历史；热搜榜数据见 M5 | 补 |

## D. 核心交互逻辑（主漏斗）

```text
输入台词 ──回车──▶ 三形态结果墙(视频循环/帧墙/GIF) ──点一条──▶ 素材详情页
   │                    │                                    ├ 取帧工作台 → 高清帧+平台裁切预设
   │ 联想/热梗补全(P1)     │ tab/exact/page 全进 URL              ├ GIF & 视频下载(水印/会员档)
   │                    │                                    └ 分享面板 → 抖音/小红书(P0) B站(P1) 微信(P1)
   │                                                            （存相册+复制文案+唤起App+短链回流页）
   └─ 首页=搜索框(莫兰迪底；强调色全站一屏最多出现一次)
```

**四条交互铁律（继承并修正 GetYarn）**
1. **URL 即状态机**：一切筛选/形态/裁切状态可分享复现——补齐 Yarn 缺的收紧参数（`exact`、画幅、page）。
2. **搜索永不空手 + 验证 ≤2s**：桌面自动循环、移动点触播放；宁可海量弱相关，不给死胡同，但给一键收紧。
3. **分享=存+复制+唤起，三段兜底**：不把任一平台 SDK 审核结果写进主链路生死线；回流页独立于唤起成功率。
4. **克制即体验（设计验收项）**：圆角体系 8/10/14/full；阴影仅两级微质感；动效 ≤240ms；同屏强调色 ≤2 处；一屏信息密度低于 Yarn 一档。
